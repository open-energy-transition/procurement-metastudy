# Emissionality

Emissionality is a strategy that seeks to purchase renewable energy from locations where it has the highest impact on emission reduction.

- **Marginal Operating Emissions Rate (MOER)**: Marginal change in emissions from short term changes in load to dispatch of fixed capacity. Can be calculated historically from input grid data using either regression methods, or transmission constraint analysis.
- **Marginal Build Emissions Rate (MBER)**: Marginal change in emissions from long term changes in load to capacity and generation of the grid. Can be calculated historically from recent build using formula described by the GHGP and UNFCCC.
- **Combined Marginal Emission Rate (CMER)**: MOER + MBER. Current guidance suggests to use both signals in some weighted combination.
